# AI-Assisted Development

This project has used AI assistance as a reviewed engineering aid.

## Confirmed Uses

- **ChatGPT:** planning, review, technical discussion, and documentation guidance.
- **Codex:** repository inspection, implementation assistance, debugging, and review.

## Human Accountability

Human decisions control the architecture, safety boundaries, dataset handling, implementation scope, and final public claims. AI-generated suggestions are reviewed before acceptance and are not treated as authoritative evidence.

## Data Handling

Raw biomedical datasets should not be uploaded to external AI tools. Sensitive, licensed, or otherwise restricted data handling remains the responsibility of the human project owner, including verification of access, privacy, licensing, and redistribution requirements.

AI assistance does not establish model quality, clinical validity, dataset rights, or regulatory compliance.
