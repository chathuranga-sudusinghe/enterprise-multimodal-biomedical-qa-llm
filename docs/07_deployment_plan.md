# Deployment Plan

Deployment is deferred during the foundation phase.

## Planned Direction

- Begin with local development and testing.
- Add controlled cloud workflows only after data governance and evaluation plans are reviewed.
- Use enterprise access controls, audit logging, and monitoring for any future clinical environment.
- Keep model hosting and fine-tuning infrastructure separate from this initial foundation.

No Docker files, deployment manifests, model serving code, or cloud automation are included yet.
